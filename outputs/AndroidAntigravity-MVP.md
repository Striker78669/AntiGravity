# Android Antigravity MVP created

The runnable Phase 1 foundation is in the workspace folder `AndroidAntigravity`.

Start the FastAPI demo backend with the commands in its README, then open the Android folder with Android Studio. The Android app defaults to the Android emulator's host alias (`10.0.2.2:8000`) and streams a demo assistant response while preserving the conversation locally.

Before the first Android build, install/configure JDK 17+; this machine currently exposes Java 8 only. Production work still needs your Google OAuth configuration and a server-side Antigravity/Gemini provider adapter—keys should never be included in the app.
